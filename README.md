# CareerOS — Career Intelligence Platform

CareerOS is a web-based career preparation platform designed to help students improve their resumes and prepare for technical interviews.

## Features

- **Resume Analyzer:** Analyzes resume content and provides a score, identified skills, strengths, and suggestions for improvement.
- **AI Mock Interview:** Generates interview questions and evaluates answers with feedback.
- **User Authentication:** Provides registration and login functionality.
- **Interview Feedback:** Helps users understand their performance and areas for improvement.

## Getting Started

### Prerequisites

- Java and a compatible JDK
- Maven
- MySQL
- A modern web browser

### Backend Setup

1. Configure your local database and Gemini API key using your private application configuration.
2. Open the `careeros-backend` folder in Eclipse or another Java IDE.
3. Configure the database connection and required environment settings.
4. Run `CareerosBackendApplication.java`.

### Frontend Setup

1. Open the `frontend` folder in Visual Studio Code.
2. Open `index.html` using Live Server, or serve the frontend using a local web server.
3. Ensure the frontend API URLs point to your running backend.

## Security

Keep API keys, database passwords, and other private configuration out of version control. Use local configuration files or environment variables for secrets.
